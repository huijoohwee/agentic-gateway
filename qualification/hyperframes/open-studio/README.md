# Open studio invitation

This original MIT-licensed, three-second invitation uses two overlapping text clips. The first card appears at zero and ends at two seconds. The second appears at one second and stays to the end. Paint order in the overlap follows DOM order. The source is 320 × 180 CSS pixels.

Run the pinned HyperFrames 0.9.85 CLI against the directory. Inspect one PNG per invocation at 0.5, 1.5 and 2.5 seconds. Import the identical full HTML into Graph’s HTML video node. Check compatibility in the node inspector, preview at the same three times, and decode the exported video. Compare the title and subtitle ink bounding boxes, background and overlap colors, visible clips and dimensions. The report in the parent qualification directory records the observed tolerances.
